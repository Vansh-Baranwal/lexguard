# LEXGUARD — AI Contract Intelligence System

> *Before you agree, understand the risk.*

LEXGUARD is a cinematic AI-powered legal intelligence platform that analyzes contracts, offer letters, quotations, ticket terms, and online policies to detect exploitative clauses, hidden liabilities, legal ambiguities, and real-world risks before users agree to them.

Built for modern digital consent, LEXGUARD transforms dense legal language into understandable risk intelligence using AI, gesture interactions, proof verification systems, and immersive legal visualization.

Every day, millions of people accept agreements they never truly understand.

# ⚡ Installation

## Clone Repository

```bash
git clone <your-repo-url>
cd lexguard
```

## Install Dependencies

```bash
npm install
```

## Setup Environment Variables

Create `.env.local`

```env
GEMINI_API_KEY=your_key

NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_bucket
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

---

# 🧪 Run Locally

```bash
npm run dev
```

Production Build:

```bash
npm run build
npm run start
```
